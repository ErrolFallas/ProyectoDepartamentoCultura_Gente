# Frontend — pendiente (Fase 5)

Esta carpeta queda reservada para la SPA en **React + Tailwind + Recharts**
descrita en la Sección 10 del Plan Maestro. Se construirá en una iteración
posterior. Paneles previstos:

1. Comparador (hasta 3 empresas/departamentos).
2. Semáforo de alertas.
3. Asistente de notificaciones al iniciar sesión.
4. Tendencias e histórico (snapshots).
5. Catálogo de preguntas (con bandeja de revisión de polaridad).
6. Generador de presentación `.pptx`.

Esqueleto sugerido:

```
frontend/
├── package.json        # vite + react + tailwind
├── src/
│   ├── main.jsx
│   ├── App.jsx
│   ├── api/
│   │   └── client.js   # fetch wrapper con JWT
│   ├── pages/
│   ├── components/
│   └── lib/
└── ...
```
